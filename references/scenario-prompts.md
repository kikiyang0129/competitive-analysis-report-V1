# 不同场景的竞品分析提示词

按用户选择的分析目标读取对应模板。不要原样机械输出，需替换为用户的行业、产品、竞品和输出要求。

## A. 判断机会

```text
请帮我做一份【某类产品/行业】的战略型竞品分析。目标是判断这个赛道是否值得进入，竞争格局如何，未来 6-12 个月有哪些机会和风险。

请区分直接竞品、间接竞品、替代方案和潜在竞品，重点分析市场格局、用户需求、产品定位、商业模式、进入壁垒、风险和机会点。

最终输出：摘要结论、竞品分类、定位对比、机会判断、风险清单和行动建议。
```

## B. 规划产品

```text
请对【某类产品】做一份产品功能与用户体验竞品分析。目标是为产品规划和体验优化提供参考。

请围绕核心任务路径，而不是只做功能清单。每个维度比较是否支持、功能深度、完成效率、用户成本、体验亮点、明显短板和可借鉴点。

关键任务流程对比必须结构化呈现，优先使用表格或分点字段：路径、产品、关键流程、竞品差异、行动判断。不要把一个路径写成连续长段落。

最终输出：核心功能矩阵、关键任务流程对比、体验问题清单、差异化总结和功能优先级建议。
```

## C. 优化体验

```text
请围绕【某类产品】做一份用户体验竞品分析。目标是发现关键路径上的阻塞点、认知成本、转化摩擦和体验机会。

请先定义 5-8 个核心任务路径，再逐个比较各竞品的入口、步骤数、完成时间、失败点、反馈机制、权限/登录/付费阻塞和可借鉴设计。

每条路径用表格或分点拆开，不要使用连续长段落；每条路径至少包含关键流程、竞品差异和行动判断。

最终输出：关键路径地图、体验问题清单、优秀体验做法、应规避问题和我方体验优化建议。
```

## D. 设计商业化

```text
请围绕【某类产品】做一份商业模式与定价竞品分析。目标是判断竞品如何收费、免费和付费边界如何设计、用户为什么愿意付费。

请重点分析套餐结构、权益设计、价格锚点、付费触发点、目标客户预算、销售路径、成本结构和商业化风险。

最终输出：价格对比表、免费到付费边界、付费理由、可借鉴套餐设计、定价建议和风险。
```

## E. 做增长

```text
请对【某类产品】做一份增长运营竞品分析。目标是理解竞品如何获客、激活、留存、转化和推荐。

请按认知、访问、注册、激活、留存、转化、推荐拆解漏斗，分析官网、SEO、内容、社媒、活动、模板、案例、渠道合作和销售线索获取。

最终输出：增长漏斗对比、渠道策略、内容打法、激活机制、转化机制和增长实验清单。
```

## F. 采购/选型

```text
请帮我做一份【某类工具】采购选型型竞品分析。目标是比较哪些产品更适合购买、替换或纳入供应商候选。

请重点分析核心能力、价格、部署方式、安全合规、权限管理、集成能力、服务支持、迁移成本、使用门槛和风险。

最终输出：选型评分表、适用场景对比、推荐短名单、采购风险、验证清单和下一步试用计划。
```

## 管理层表达

管理层不是分析目标，而是阅读对象。若用户选择老板/管理层作为阅读对象，应调整表达：

- 结论前置。
- 控制细节，保留证据链。
- 强调机会、风险、取舍、资源投入和下一步。
- 表格不宜过多，优先摘要卡片、定位图、评分矩阵、行动建议。
- 如果输出 PPT 大纲，控制在 8-12 页。
