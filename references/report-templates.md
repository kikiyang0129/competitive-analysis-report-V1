# 报告结构模板

## Markdown 长报告

适合标准版和深度版。

```text
# 【主题】竞品分析报告
## 1. 摘要结论
## 2. 分析目标与范围
## 3. 竞品选择与分类
## 4. 市场/用户/定位分析
## 5. 核心维度对比
## 6. 关键任务路径对比
## 7. 关键洞察
## 8. 机会、风险与行动建议
## 9. 评分口径、未查证项与来源
```

## HTML 可视化报告

适合需要阅读体验、分享或归档的报告。

模块：

- 封面标题和元信息。
- 摘要结论卡片：`## 摘要结论` 下的 3-6 条 bullet 会自动卡片化。
- 目录。
- 分析任务卡。
- 核心矩阵：优先使用 1-5 分评分矩阵，第一列为维度，后续列为竞品。
- 自动图表：评分矩阵会自动生成雷达图、四象限、综合评分排行和热力表格。
- 关键路径：用表格或分点呈现，字段建议为“路径/产品/关键流程/竞品差异/行动判断”；关键流程中可用 `步骤一 → 步骤二 → 步骤三` 表达，方便自动生成流程图。
- 重点洞察。
- 建议和优先级：可用 `Must:`、`Should:`、`Could:` 开头，或使用 `优先级 | 建议 | 动作说明` 表格，方便自动生成看板。
- 评分口径：说明评分矩阵、图表、排行和优先级建议的依据。
- 未查证项：列出资料不足、无法确认或可能过时的信息。
- 来源列表：包含主要来源、访问日期或访问口径；优先用短标题 + Markdown 链接，避免整页展示超长 URL。

使用 `assets/html-report-template.html` 或 `scripts/build_html_report.py`。

## PPT 汇报大纲

适合老板、管理层、客户、投资人。

推荐 8-12 页：

1. 标题页：主题、时间、分析目标。
2. 一页结论：3-5 条关键发现和建议。
3. 分析范围：竞品名单、分类和选择理由。
4. 市场/用户/定位核心判断。
5. 关键能力或维度对比。
6. 关键路径/体验/商业/增长发现。
7. 机会点与差异化方向。
8. 风险和不建议做的事项。
9. 行动建议和优先级。
10. 附录：评分口径、未查证项、来源和方法。

## 竞品对比表格

适合快速选型或专项分析。

字段建议：

- 产品名称。
- 类型：直接/间接/替代/潜在。
- 定位。
- 目标用户。
- 核心能力。
- 价格/商业模式。
- 体验亮点。
- 主要短板。
- 可借鉴点。
- 风险。
- 证据状态：已查证/未查证/待验证。
- 来源。

## 快速版

输出：

- 3-5 条摘要结论。
- 竞品列表和选择理由。
- 一张核心矩阵。
- 3 条行动建议。
- 评分口径和来源列表。
- 必要时列出未查证项。

## 标准版

输出：

- 3000-6000 字。
- 5-8 个竞品。
- 核心矩阵、关键路径、洞察和建议；关键路径必须结构化，不输出连续大段文字。
- 来源列表。
- 评分口径和未查证项。

## 深度版

输出：

- 8-12 个竞品。
- 多维度拆解。
- 证据来源、评分模型、附录表格。
- 明确风险、假设和待验证问题。

## 事实呈现口径

报告中涉及事实、判断和建议时，按下列口径呈现：

- 事实发现：来自公开来源、用户材料或可复核数据，需要标注来源。
- 分析判断：基于事实和评分口径形成，必须说明判断依据。
- 行动建议：基于目标和取舍给出，需要说明适用前提。
- 未查证项：不要写成确定事实，统一标记为“未查证”“待验证”或“不确定”。
