# HTML 和文档排版风格

用于指导 HTML 报告和 Markdown 报告的视觉层级。默认使用本 skill 内置模板，不依赖其他 skill。

## HTML 自动可视化

生成 HTML 报告前，优先让 Markdown 内容具备可视化友好的结构：

- `## 摘要结论` 下使用短 bullet，生成摘要卡片。
- 评分矩阵使用 1-5 分，第一列写维度，后续列写竞品，生成热力表、雷达图、四象限和综合评分排行。
- 关键任务路径使用 `→` 连接步骤，生成横向流程图。
- 优先级建议使用 `Must:`、`Should:`、`Could:`，生成三列看板。
- 表格标题和维度名称要短，避免图表标签过长。

## A. 专业咨询风

适合：老板、客户、投资人、管理层汇报。

风格：

- 结论前置。
- 颜色克制：深蓝、灰、少量强调色。
- 使用摘要卡片、关键数据卡片、评分表、行动建议框。
- 表格信息密度中等，避免长段落塞进表格。
- 标题短，动词明确。

## B. 产品经理工作文档风

适合：内部评审、产品规划、需求讨论。

风格：

- 重功能矩阵、关键路径、体验问题和优先级。
- 清楚列出 Must / Should / Could。
- 用表格承载重复字段，用段落解释判断。
- 语气直接、可执行。

## C. 数据看板风

适合：竞品很多、评分很多、指标对比多的报告。

风格：

- 突出评分、权重、趋势、矩阵和指标。
- 使用数据卡片、热力矩阵、排名表。
- 优先把核心能力做成 1-5 分矩阵，让 HTML 脚本自动生成图表。
- 每张表后必须写“怎么解读”，避免只有数字。

## D. 极简黑白风

适合：打印、归档、二次编辑。

风格：

- 黑白为主。
- 少用颜色和阴影。
- 表格边框清晰。
- 留足页边距和行距。

## E. 汇报展示风

适合：客户、投资人、外部合作方和公开读者。

风格：

- 结论清晰，层级明确。
- 保留必要证据，减少过程性长段落。
- 重点使用摘要卡片、对比矩阵和行动建议。
- 表格控制宽度，优先展示关键字段。

## F. 自定义风格

用户选择此项时，继续问：

```text
请描述你想要的排版风格，例如：偏咨询公司、偏 Notion 文档、偏数据看板、深色科技风、适合打印等。
```

不要替用户虚构风格。
